## Project Description

This project is a Student Management System built using Java Swing.

The application allows users to create, view, update, and delete student records through a graphical user interface.

The main goal is to practice Java programming, Git, GitHub, commits, branches, and Pull Requests.

## Features

| Operation | Description |
|-----------|-------------|
| Create | Add new students |
| Read | View students in a table |
| Update | Edit student information |
| Delete | Remove students |

### Additional Features

- Graphical user interface using Java Swing
- Automatic student ID generation
- Input validation
- Student selection from a table
- Console logging for CRUD operations

## Technologies Used

- Java 25
- Java Swing
- Git
- GitHub
- macOS

No external dependencies are required.

## How to Run

### Requirements

Java JDK 17 or newer must be installed.

### 1. Clone the Repository

Run: `git clone https://github.com/the0kan/First-Java-CRUD.git`

### 2. Open the Project

Run: `cd First-Java-CRUD`

### 3. Compile the Application

Run: `javac src/StudentManagementApp.java`

### 4. Start the Application

Run: `java -cp src StudentManagementApp`

The Student Management System window will open.

## How to Use

### Create
Enter a name and email, then click "Add Student".

### Read
All students are displayed in the table.

### Update
Select a student, change the information, and click "Update Student".

### Delete
Select a student and click "Delete Student".

Note: Data is stored in memory and resets when the application closes.
