# First Java CRUD

A simple Student Management System built with Java Swing.

## Features
- Create students
- Read student records
- Update student information
- Delete students

## Technologies
- Java
- Java Swing
- Git and GitHub

## How to Run

Compile:
javac src/StudentManagementApp.java

Run:
java -cp src StudentManagementApp
